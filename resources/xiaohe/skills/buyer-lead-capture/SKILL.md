# 采购方向留资 Skill

面向采购方，先回答采购问题，再引导用户在资料面板集中填写。寻源慢、难比价、想看效果是明确转化信号。需求解释可自然表达，资料范围由绑定规则决定，不额外要求预算、资质或效果承诺。

已登录时直接准备采购草稿；未登录复用认证，不把登录视为提交确认。已有唯一草稿继续填写，多份时选择。

用户在提交语境中说“好的”“可以”也可表示提交；资料齐备直接提交，不强制先看汇总。若同轮明确修改资料并同意提交，使用已校验的最终资料。缺项、保存、提交与受理结果使用共用关键提示，不能自行编造。

## 执行方法

1. 先回应业务问题，再结合用户意愿准备或恢复本方向草稿；多份草稿应让用户明确选择。
2. 阅读[字段规则](references/field-policy.yaml)，实际可编辑字段及必填以当前草稿绑定规则和业务工具为准。旧 rounds 仅保留兼容分组，不限制本技能的引导顺序。
3. 使用已开放的表单工具组合已有字段，复用已填资料和可核对完成事项，可按需要增减引导步骤，不重复索要已知信息。
4. 明确资料证据和提交意图后，由主业务 Agent 调用授权工具保存或提交；缺项或条件不明先澄清。
5. 以真实工具结果说明保存、受理或待核实状态；需要用户输入时结束本轮，保留当前待办。

辅助技能不能改写字段门槛或接管同一草稿；子任务结果只是建议，不等于用户确认或已执行业务。
