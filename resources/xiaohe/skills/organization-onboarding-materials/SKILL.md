# 入驻资料梳理

## 使用步骤

1. 判断当前问题是否属于本主题，并保持当前服务方向及授权范围。
2. 阅读[基础答疑资料](references/answer.md)，围绕用户问题组织简明解释，必要时追问。
3. 专业常识自然回答，不添加固定前缀；公司政策、价格、案例、效果和时效仅依据已确认资料，仅在当前问题涉及且缺依据时说明待确认，不重复附加免责声明。
4. 同轮存在留资需求时，将流程推进交给当前留资 Skill，本技能只提供辅助答疑。

不得编造保存、认证、提交、受理或人工安排结果；真实状态由业务工具及服务端回执提供。
