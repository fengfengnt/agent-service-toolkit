## 平台与公司

平台名称：云鹤智元；英文品牌：Yunhe Zhiyuan。公司全称：云鹤智元（上海）科技有限公司。

公司是商用人工智能解决方案专业服务商，围绕企业供需提供智能体、数据及 API 服务，改善业务效率、客户连接与资源利用。品牌表达包括“企业供需，你需故我在！”和“让好的供给，匹配对的需求！”。

服务企业、社群组织、超级个体、创业团队与技术团队，连接采购方、供应商和社群组织；同一企业可按实际诉求使用多类服务。

公司建设 NexFount 大模型 API 云服务平台；2025 年与采购中国共同训练企业级采购智能体。

## 助手与合作品牌

- **小鹤**：官网智能服务助手，承接公司咨询，按采购、社群组织、供应方向连接专业服务。

- **天下溪**：面向商协会、商会、校友会、产业联盟和垂直社群的智能体训练、会员平台及资源连接方案，强调信任、过滤、互动、链接、生态。组织知识和会员服务可试点，运营、品牌与收益安排需确认。
- **天下式**：面向中小企业供应商，以“一家企业，一个智能体，一份可验证的能力档案”为方向，以本体提取、持续完善和 A2A 互联支持接待与供需连接，不保证曝光、排名、订单或收入。
- **NexFount**：模型与供需业务 API 入口；具体型号、接口、价格、限流、区域及权限以当前目录和服务说明为准。
- **智元创投**：面向有业务、盈利基础和真实场景的团队，讨论 AI 商业模式、资金、算力与技术合作；资格、投入、权益和评审需确认，申请不等于获批。

天下溪、天下式介绍免费智能体训练，对象与范围需核实。平台、模型调用、存储、定制、交易和维护是否收费分别确认，不推定全部免费或已确定收费。

## 合作流程与资料

合作通常经过咨询、需求梳理、评估、范围商务确认、资料授权、配置联调、验收上线和维护，以真实记录为准。

| 对象 | 初步沟通资料 |
| --- | --- |
| 企业与采购方 | 行业、品类需求、数量、区域、痛点、系统和期望时间；预算与立项可后续沟通。 |
| 社群组织 | 组织类型、会员规模行业、服务、痛点、授权资源和合作方式。 |
| 供应商 | 主营产品服务、区域、产能、公开资质案例、问答与报价边界。 |
| API 与集成团队 | 系统版本、环节、接口、数据审批边界、测试与调用量。 |

资料类别供沟通参考，必填项和附件以当前表单为准，咨询无需交齐敏感资料。知识需有来源、范围和维护人，过期资料、未授权案例及未确认的模型回复不直接作为事实。

注册、草稿、提交、受理和交付是不同状态，不由注册推定签约、获批或订单。“我的进展”以本人记录和工具回执为准，方案中的合同、结算、分派及通知能力不认定已全部上线。

## 技术、授权与待确认边界

“训练企业智能体”可涉及知识、检索、流程和模型适配，不默认指微调或重训基础模型。连接器及改造量需核实，不预设任意系统零改造接入。

A2A 指智能体间协作，共享、自动应答与人工确认由参与方授权，不默认允许交换机密或代表企业签约、付款、确认交期及最终报价。

价格、优惠、分成返佣、账期、退款与开票规则待确认。案例、演示和售后需核实，不将测试或示意当作客户案例，不承诺固定收益或保底订单。
