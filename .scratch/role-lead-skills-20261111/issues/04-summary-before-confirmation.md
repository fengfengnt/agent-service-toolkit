# 尚未展示汇总时的提交顺序

Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: 当前对话
Blocked by: 03

## Question

资料齐全但还未展示汇总，用户直接表达“可以提交了”，LLM 已认定用户同意提交时，应直接提交，还是先展示汇总再等一次确认？

## Context

口语确认有效性已在“正式提交的确认入口与约束”中确定。本票只决定展示汇总与正式提交的先后关系，不再讨论固定句式或短语白名单，不调整必填项。

当前实现的正式确认绑定已展示的汇总版本；若业务选择允许更早提交，后续设计需明确如何统一提供不可省略的提交确认提示，并保持确认资料与实际提交资料一致。本阶段不修改代码或生产。

## Answer

2026-11-11，用户选择：直接提交。

因此，现有必填资料已齐全、LLM 根据上下文认定用户同意提交时，不把“先展示汇总并再次确认”作为前置条件。三角色采用相同确认规则；Artifact 按钮仍可作为提交入口，汇总展示可供用户主动查看。

用户此前确认的必填提示、提交告知与真实受理结果约束继续保留。后续设计应将必要告知与提交动作在同一轮完成，不再额外询问一次；受理成功只能由真实回执确认。现有身份、权限、资料版本一致性和防重复提交检查不因取消二次确认而取消。

以上仅记录目标设计；当前代码仍有汇总前置检查，尚未修改实现或生产。
