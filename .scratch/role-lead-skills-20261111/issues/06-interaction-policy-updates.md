# 通用交互规范更新对既有草稿的影响

Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: 当前对话
Blocked by: 05

## Question

通用话术或交互规则更新后，既有草稿是否从下一轮用户对话起采用新版交互规范，同时保持原字段要求，并让已发出的提交继续沿原请求核对？

## Context

用户已确认字段规则按草稿版本保留。本票只讨论交互规范，包括口语提交确认、直接提交及关键提示等，不重新讨论字段门槛。

建议对后续对话应用已发布的新交互规范，使旧草稿也获得交互修复；执行中的动作不临时换规则，已发出的提交不重建或重放。现有 bundle 将字段和提示词共同固定，最终方案需明确两者的装配与记录方式。这一建议尚待用户确认。

## Answer

2026-11-11，用户同意：已有草稿从下一轮对话起使用新版话术和交互规范，原字段要求不变；执行中和已发出的提交按原请求处理。

因此，字段规则按草稿固定；交互规范按新用户轮次选择已发布版本，并在本轮执行期间固定。不能因为规范更新而修改执行中动作、替换已发出的提交内容或生成新的提交键。这里只记录设计，未改实现或生产。
