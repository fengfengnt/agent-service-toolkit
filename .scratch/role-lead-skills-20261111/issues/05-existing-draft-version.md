# Skill 更新后既有草稿的字段规则

Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: 当前对话
Blocked by: 04

## Question

未来产品经理调整字段规范并发布新 Skill 时，已经填写中的草稿沿用创建时的字段要求，还是跟随新版本？

## Context

本轮不调整任何必填项。本票只决定未来规范发布对既有草稿的影响，不重新讨论必填字段内容。

建议新草稿采用新版字段规则，既有草稿保留原字段要求，避免用户填写中途被增加资料要求。当前代码已存在 definition_bundle_id 绑定草稿规则的机制，设计可优先复用；业务选择仍待用户确认。通用交互规则与字段规则的版本边界应在最终设计中明确。

## Answer

2026-11-11，用户同意：新草稿用新版字段规则，已有草稿保留原字段要求。

字段规则更新不自动改变既有草稿的字段、必填或校验要求，不覆盖已经填写的资料。本轮不调整任何必填内容。

本票只确认字段规则的版本策略；话术、语义提交及其他通用交互规则对既有草稿如何生效，另见后续决策。

## Design notes

现有实现将工作流、提示词和资料规则放在同一 bundle 中，并存在历史规则的有效门槛投影。后续设计需区分字段规则与通用交互规则的生效边界，核对存量草稿实际采用的字段口径，不能只凭存在 definition_bundle_id 就认定所有历史要求已经完全固定。本阶段不修改这些实现。
