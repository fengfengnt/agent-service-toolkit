# 外部 Skill 的依赖与脚本启用

Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: 当前对话（标准 Skill 与 DeepAgents 接入设计）
Blocked by: 02

## Question

外部导入的 Skill 引用了脚本、特定工具或运行环境时，首版支持哪些能力，导入、兼容检查、绑定和启用怎样区分，哪些能力需适配后才能使用？

## Context

本票讨论标准说明、引用资源与执行依赖的导入和启用边界，不要求每份外部 Skill 无需适配即可执行。

## Answer

2026-11-11，用户对“导入后由 Codex 检查并绑定，执行能力通过授权工具接入”的首版方案回答“是”。

- 导入时保留标准 Skill 目录及引用资源，说明和参考资料供 DeepAgents 按需读取。
- Codex 在绑定节点或 subagent 前检查格式、依赖和所需权限。
- 需要执行的能力通过明确授权的业务工具接入；脚本所需能力可以先适配为工具，通用脚本执行环境及隔离方案后续另行设计。
- 缺少工具、脚本运行条件或其他必要能力时，明确标记尚不可用及缺失原因，适配完成后再启用，不声称已执行成功。
- Skill、后端接口、前端界面可按需要配合修改和发布，延续用户此前已确认的维护方式。
