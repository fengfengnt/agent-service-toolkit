# 留资组合调整后的执行状态与版本兼容

Assignee: 当前对话（标准 Skill 与 DeepAgents 接入设计）
Blocked by: 01

## Question

Skill 重新组织已有字段和引导步骤后，怎样记录执行进度、等待用户输入和子任务结果；如何落实旧草稿保留字段要求、新轮次可更新交互、在途动作不换版的既有约定？

## Context

- 既有版本约定已由用户在关联规划聊天中确认：草稿字段规则固定，下一轮可使用新版交互规范，执行中动作及已发出的提交保留原请求。
- 本票讨论新版 Skill 接续已有草稿时，以已有资料和可核对的已完成事项重新判断待办，不按旧步骤序号机械映射，也不要求用户从头填写。
- 已填资料继续按草稿原规则使用；新增引导步骤不能擅自提高旧草稿的字段门槛，不能将尚未执行的新增事项记成已完成。
- 执行中的本轮动作、工具重试和已发出的提交继续使用原版本及原请求。
- 实际进度表示和 DeepAgents 状态恢复接口留给设计及兼容性调查，不在本票提前锁定实现细节。

## Answer

2026-11-11，用户对“保留已有资料与完成记录，重新判断待办步骤”的接续方式回答“是”。

- 已有草稿保留原字段要求及已填资料；下一轮可以采用已发布新版 Skill 的交互引导。
- 根据已有资料和可核对的已完成事项确定新版待办，不机械沿用旧步骤序号，不要求用户重复填写已有信息。
- 新增且尚未完成的必要引导继续执行；新增步骤不能擅自提高旧草稿的必填门槛，也不能把未执行事项记成完成。
- 步骤完成不能只从字段已填写推断；解释资料用途等非字段事项也需有可核对的完成依据。
- 执行中的本轮动作、工具重试及已发出的提交保持原版本和原请求，避免更新后重复执行业务。
