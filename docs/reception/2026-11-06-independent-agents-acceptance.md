## 真实模型语义层

全部身份、组织和资料为虚构数据；独占 PostgreSQL 和内存业务适配器，不发送短信，不提交真实业务。四个 Agent 各8项，共32项。检查代码校验后的动作和真实受控副作用，保留模型原始结构化建议用于诊断；不保留内部推理和凭据。

## 交付边界

四个 Agent 使用现有LangChain／LangGraph，无DeepAgents。YAML为实际定义，提示词和材料随bundle冻结。权限、必填、汇总版本、幂等和提交仍由代码控制。现在一起部署，未来分离仅保留装配边界与注释；未增加单独部署包、RPC、流程编辑或导出功能。

本轮只提交功能分支与必要门户调用方变更，不自动合并、推送或部署。原有未提交工作保留；验收针对当前工作区加本次增量，不把原有未提交工作打入本次提交。主合同第11节同步可选布局增量，第12节生命周期设计不变。

Chrome已获用户授权。个人已打开窗口的连接被工具URL安全检查阻止，未操作或验收该窗口；后续使用隔离Chrome会话。
