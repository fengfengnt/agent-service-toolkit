# 小鹤回答、身份交接和留资入口修复验证

日期：2026-11-12。修复针对用户提供的两张 WSL 截图。本轮修改后端与 `D:/Code/yunhezhiyuan-portal` 前端源码；尚未发布，WSL 仍使用 AI 0.1.8／Portal 0.1.30。

## 原因与行为

后端按 `AnswerDraft.basis=general_advice` 固定拼接“一般建议：”，标准问答 Skill 又要求通用常识标注一般建议，导致重复口径。现在保留内部来源类型，直接展示自然回答；18 个问答 Skill 同步取消固定前缀要求，具体政策事实缺依据时仍需说明待确认。

欢迎页的身份按钮原先只发送普通文本，实际方向依赖模型调用 `request_handoff`。模型只回复“社群组织方向”不会更新会话方向。现在三个身份按钮调用受控 `switch_direction`，接口补齐 buyer，前端刷新权威状态后显示对应专家。自然语言仍由接待 Agent 语义交接，指令明确首次身份选择必须调用交接工具，不要求用户再次说“切换”。没有增加正则路由执行链。

页脚原先在已登录时显示角色、未登录时显示认证按钮，现在统一显示“注册/登录”链接样式按钮。右上专家名称仍取服务端会话方向，不从用户输入推测或伪造。

模型产生的 `</br>` 原先经文本插值直接显示。后端普通回答和前端已有消息中的 br 换行标记转成真正换行，其他文本继续安全插值，未启用任意 HTML。

普通咨询的待输入提示改为“您可以进行咨询或者留下您的信息”，最后部分使用可键盘操作的链接样式按钮。点击复用受控邀请／认证续接；方向不明时先由接待确认。登录后的新建或采集中草稿进入对应业务 Agent，加载绑定的标准留资 Skill。待复核、已受理及提交中的现有草稿维持原恢复路径，不因入口点击新建申请。`accept_invitation`／`start_collection` 与认证续接均不能作为正式提交同意，工具层拒绝在这些 Command 中调用 `submit_lead`。

## 验证

所有可清空数据库测试仅连接专属容器 `xiaohe-chat-ux-tests-20261112` 的 `test_xiaohe_agent`，没有清空现有 WSL 业务库。认证浏览器测试使用替身，不发送真实短信、不提交正式业务。

- 初始后端回归复现 5 个失败：不接受 buyer 方向、拒绝从 none 接受留资、三方向回答强制前缀且保留 br。
- 初始浏览器 4 个失败：已登录页脚仍显示角色，三个欢迎身份按钮未更新专家状态。修改后通过；追加访客留资先进入登录的用例通过。
- 三方向留资入口绕过 Skill 的测试先复现 3 个失败；改为采集中运行绑定 Skill 后通过。入口不是提交同意的工具边界测试先复现 2 个未拒绝调用，增加门槛后通过。
- 最终后端集合 `test_chat_entry_ux.py`、`test_deep_runtime.py`、`test_deep_journeys.py`、`test_deep_tools.py`、`test_deep_review_regressions.py`：**62 passed**。另行执行的 partner／welcome／factory 等相关集合为 **27 passed**；字段策略／表单／effects／标准包等相关集合为 **42 passed**，部分案例与最终集合重合，不能相加作为独立案例总数。
- 前端可用性、控制契约、store、登录续接、展示和 v2 策略 7 个单测文件：**71 passed**；`npm run typecheck` 和 `vue-tsc --noEmit` 通过。
- 四个浏览器文件覆盖 32 个案例：首轮 28 通过；因新增可聚焦页脚按钮更新 4 个旧焦点断言后，3 个通过，320px 用例首次加载失败、单独重跑通过。覆盖安全插值、流式、额度、身份更换、滚动和 320／390／768／1440px 焦点约束。
- 独立构建的 SSO 浏览器集合：**3 passed**，覆盖两种伙伴方向交接保留账号对话，以及“留资链接→一次认证→采集表单”，断言未执行正式提交动作。
- 修改范围 Ruff、Python 编译及 `git diff --check` 通过。

独立审阅发现 2 个 Important，并在同一轮修复：已接受邀请的访客应直接恢复认证；访客消息额度用尽时，留资控制入口不能随聊天发送一起被禁用。两个浏览器用例先复现登录无法恢复与按钮不可点击；修改后分别核验。控制入口继续使用共有的过期、忙碌、断线、身份和权限检查，并校验当前问题，额度豁免仅适用于控制动作。已有 guest 草稿同样先认证；不会直接调用要求会员身份的 `start_collection`。

审阅修复后的入口浏览器集合 **7 passed**；最终类型检查通过。审阅仅一轮，修复通过回归核验，没有声称 reviewer 再次审阅或真实模型通过。

真实模型使用三种合成身份的工具交接探针在 TLS 读取阶段超时，未得到完成结果；不能将脚本模型或 UI 替身的通过说成真实模型语义交接已验。未执行本轮 WSL 部署、真实会员登录、真实短信或正式业务提交。门户已有其他未提交的认证、协议及版本修改保持原样，没有纳入本轮源码修改范围。
