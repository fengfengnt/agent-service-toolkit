# 小鹤共享知识实现与验证

日期：2026-11-16。按已批准的共享官方知识设计，在独立工作树逐项实施；本记录不代表环境已发布。

## 已实现范围

- `resources/xiaohe/knowledge/platform-common.md` 是唯一共享事实入口，四业务 Agent 和显式注册的只读 subagent 默认得到命令快照中的完整正文。正文 UTF-8 上限 8192 字节，新文件非法或缺失时拒绝发布；历史无共享文件的 Bundle 不补读新版。
- 共享内容可使用内部来源 `shared:platform-common`，关闭向量检索时也通过既有来源校验，不为普通回复强制增加来源尾句。公开共享资料不扩大子 Agent 权限，工具回执仍决定保存与提交状态。
- 共享正文可先发布。对比同源文档的完整分块摘要与元数据，未同步的所有旧条目在 Chroma 查询前排除，其他资料不被旧块挤占；独立审查补充发现同步分块也会挤占 top-k，已修正为常驻共享文档的所有条目均在查询前排除；模型装配及缓存仍去重，仅有常驻共享候选时不请求 Embedding。
- 构建和查询显式发送所选维度。在线请求超时 3 秒、整次检索 4 秒、离线建库请求 30 秒，重试为 0；保留锁、取消、忙碌准入、授权和正文完整性校验。
- 非秘密模板采用批准的 APIPro URL、`text-embedding-3-small`、1024 维；真实 Key 仍只在私有运行配置接线。本轮未读取或复制实际 Key、未修改小采或小鹤运行环境。
